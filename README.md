## 👋 About

Welcome to my personal portfolio.

This website is designed to introduce myself, showcase my skills and experience, document my learning journey, and present the projects I have worked on.

The portfolio focuses on a clean, modern, and responsive interface that can be accessed comfortably across desktop and mobile devices.

---

## ✨ Features

* 🏠 **Home** — Introduction and personal overview
* 👤 **About** — Personal information and background
* 🧭 **Journey** — Learning and development journey
* 💼 **Experience** — Experience and activities
* 🛠️ **Skills** — Technical and creative skills
* 🚀 **Projects** — Selected projects and works

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ZidzN/Portofolio.git
```

### 2. Open the project

```bash
cd Portofolio
```

### 3. Run the website

Because this project uses HTML, CSS, and JavaScript, no package installation is required.

You can open:

```text
index.html
```

directly in your browser.

For a better development experience, you can also use a local development server such as **Live Server** in Visual Studio Code.
